# PrecisionSurface Addon for Blender 3D

Bridge the gap between art and engineering with precision hard surface modeling tools.

## Overview

PrecisionSurface is a comprehensive hard surface modeling addon for Blender 3D that provides CAD-like precision within Blender's organic modeling environment. It offers a complete suite of tools for precise modeling, measurement, component management, and manufacturing preparation.

## Key Features

### Precision Tools
- Parametric modeling with exact measurements
- Precise transformation controls (Move, Rotate, Scale)
- Measurement and dimensioning system
- Constraint system for maintaining engineering tolerances

### Pattern Generation
- Linear and circular array tools
- Honeycomb pattern generator
- Smart pattern placement on surfaces

### Component Library
- Premade industrial components (screws, bolts, panels, etc.)
- Easy component placement and management
- Component parameter customization

### Manufacturing Integration
- 3D printing feasibility checker
- Fillet and chamfer tools for manufacturing
- Export tools for various manufacturing formats
- Draft angle and undercut detection

### Intuitive Interface
- Progressive complexity (Beginner, Intermediate, Advanced modes)
- Integrated tutorial system
- Context-sensitive help
- Customizable settings

## Installation

1. Download the latest release from the [releases page](https://github.com/precisionsurface/releases)
2. In Blender, go to Edit > Preferences > Add-ons
3. Click "Install..." and select the downloaded ZIP file
4. Enable the addon by checking the box next to "Modeling: PrecisionSurface"

## Quick Start

1. After installation, you'll find the PrecisionSurface tab in the sidebar of the 3D View (press N if the sidebar is hidden)
2. Start with the "Parametric Shapes" panel to create precision objects
3. Use the "Precision Tools" panel for exact positioning and measurement
4. Explore other panels for pattern creation, component library, and manufacturing tools
